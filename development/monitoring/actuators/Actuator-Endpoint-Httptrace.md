# Actuator Endpoint - Http Trace

Source: https://apereo.github.io/cas/development/monitoring/actuators/Actuator-Endpoint-Httptrace.html

The `httptrace` actuator endpoint from earlier Spring Boot versions no longer exists. Use the [httpexchanges](https://apereo.github.io/cas/development/monitoring/actuators/Actuator-Endpoint-Httpexchanges.html) endpoint to see recent HTTP requests and responses.
