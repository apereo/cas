# OpenID Connect Protocol

Source: https://apereo.github.io/cas/development/protocol/OIDC-Protocol.html

You can configure the CAS server with:

- [OIDC client support](https://apereo.github.io/cas/development/integration/Delegate-Authentication.html), which means authentication can be delegated through a link on the login page to OpenID Connect provider.
- [OIDC server support](https://apereo.github.io/cas/development/authentication/OIDC-Authentication.html), which means you will be able to communicate with your CAS server through the [OpenID Connect protocol](http://openid.net/connect/), having CAS act as an OP.
