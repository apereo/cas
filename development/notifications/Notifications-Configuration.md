# Notifications

Source: https://apereo.github.io/cas/development/notifications/Notifications-Configuration.html

CAS presents the ability to notify users and accounts on select actions via platform-specific notifications. Example actions include notification of risky authentication attempts or password reset links/tokens or one-time tokens for multifactor authentication. Providers and platforms supported by CAS are listed below. Note that an active/professional subscription may be required for certain providers.

| Provider | Reference |
| --- | --- |
| Apple Push Notification | [See this guide](https://apereo.github.io/cas/development/notifications/Notifications-Configuration-APN.html). |
| Google Firebase | [See this guide](https://apereo.github.io/cas/development/notifications/Notifications-Configuration-FCM.html). |
| Slack | [See this guide](https://apereo.github.io/cas/development/notifications/Notifications-Configuration-Slack.html). |
| Custom | [See this guide](https://apereo.github.io/cas/development/notifications/Notifications-Configuration-Custom.html). |
